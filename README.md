# 🌀 Doctor Strange Portal Effect using AI Hand Tracking

Create cinematic **Doctor Strange-inspired magical portals** using **AI hand tracking**, **MediaPipe**, and **OpenCV**. Draw circles in the air with your hand to summon an animated magical portal with glowing runes, particles, sparks, and rotating symbols.

- 🖐️ AI Hand Tracking using MediaPipe
- 🪄 Doctor Strange Magic Circle Effect
- 🌀 Air Drawing Gesture Recognition

- ⚡ Rotating Magical Runes
- 💫 Dynamic Portal Animation
- 🤜 Left-Hand Fist Activation
- ✋ Open Palm Detection
- 🎥 Real-Time Webcam Processing

# ⚙️ How It Works

1. Webcam captures live video.
2. MediaPipe detects both hands.
3. Open palms display magical rune circles.
4. Make a fist with the left hand to enable portal creation.
5. Draw a circular motion with the right index finger.
6. The system recognizes the completed loop.
7. A magical Doctor Strange portal appears with rotating symbols, sparks, and particle effects.
